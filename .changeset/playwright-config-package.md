Add `@alleyinteractive/playwright-config`: a shared Playwright config factory, screenshot helpers, and reusable GitHub Actions workflows for screenshot and functional testing.

Includes an `alley-playwright init` command that scaffolds the config, example specs, caller workflows, and `.gitignore` entries, and can optionally add agent notes to `CLAUDE.md`.
