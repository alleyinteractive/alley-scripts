# Introduction

Alley Scripts is an experimental project of
[Alley Interactive](https://alley.com/) and serves as a laboratory where we can
iteratively build and publish functionality as discrete `npm` packages that can
be used in projects to speed up development.

On this site, you can find documentation for each package, as well as
interactive components for each package that can be used to test out the
functionality.

## Packages

The following packages are currently available:

- <LinkTo kind="Packages/Block Editor Tools" name="Documentation">`@alleyinteractive/block-editor-tools`</LinkTo>: A set of tools to help build products for the WordPress block editor.
- <LinkTo kind="Packages/Build Tool" name="Documentation">`@alleyinteractive/build-tool`</LinkTo>: An opinionated set of build configurations for wp-scripts
- <LinkTo kind="Packages/Create Block" name="Documentation">`@alleyinteractive/create-block`</LinkTo>: Alley's custom block scaffolding variation for the @wordpress/create-block script.
- <LinkTo kind="Packages/Create Entry" name="Documentation">`@alleyinteractive/create-entry`</LinkTo>: Alley's script for scaffolding code for entry points in projects that use @wordpress/scripts
- <LinkTo kind="Packages/Create Release" name="Documentation">`@alleyinteractive/create-release`</LinkTo>: Create alleyinteractive/create-wordpress-plugin releases with ease.
- <LinkTo kind="Packages/ESLint Config" name="Documentation">`@alleyinteractive/eslint-config`</LinkTo>: Alley's ESLint configuration
- <LinkTo kind="Packages/Oxlint Config" name="Documentation">`@alleyinteractive/oxlint-config`</LinkTo>: Alley's custom Oxlint and Oxfmt shareable configuration with linting and formatting
- <LinkTo kind="Packages/Scaffolder" name="Documentation">`@alleyinteractive/scaffolder`</LinkTo>: Quickly scaffold project template files.
- <LinkTo kind="Packages/Scaffolder Features" name="Documentation">`@alleyinteractive/scaffolder-features`</LinkTo>: Base features included with the Alley Scaffolder
- <LinkTo kind="Packages/Stylelint Config" name="Documentation">`@alleyinteractive/stylelint-config`</LinkTo>: Alley's sharable stylelint config
- <LinkTo kind="Packages/TSConfig" name="Documentation">`@alleyinteractive/tsconfig`</LinkTo>: Shared Typescript Configuration

The components and hooks from `@alleyinteractive/block-editor-tools` can be tried out interactively under **Block Editor Tools**. They run against a mocked WordPress REST API, so search, selection and post data work without a WordPress install.
